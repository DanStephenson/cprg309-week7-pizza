# 🍕 Slice & Dice Pizza Calculator
### CPRG 309 — Week 7: Functions Deep Dive

---

## What this is

A pizza order calculator built in class over two sessions. The UI is already written — your job is to write the JavaScript that makes it work.

By the end of the week you'll have built a fully functional order calculator that uses real function concepts: parameters, return values, composing functions, and callbacks.
